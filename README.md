# Psycho1
### руководство пользователя
#### Запуск программы
- Для запуска программы "Психо" зайдите в папку "Программа" в корневой директории и откройте файл exe
#### Инструкция по использованию
- После запуска программы нажмите кнопку "пройти тест"
- В открывшемся списке выберите тест
- Чтобы выйти со страницы выбора тестов нажмите на крестик в правом верхнем углу
- После этого вам откроется подробное описание теста
- Чтобы начать тест нажмите на кнопку в нижнем правом углу экрана "Начать тест"
- В процессе прохождения теста выберайте вариант ответа и нажимайте кнопку "далее"
- Если вы захотите вернуться на вопрос назад, нажмите кнопку "назад"
- Если вы хотите выйти из теста, нажмите на крестик в правом верхнем углу
- После прохождения теста вам высветится список из результатов
- Чтобы выйти из окна результатов нажмите на кнопку выход в нижней части экрана
